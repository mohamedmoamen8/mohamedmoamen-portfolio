# Mohamed Moamen's Portfolio

A modern, interactive portfolio website built with clean HTML, CSS, and JavaScript.

## 🎯 Features

- **Responsive Design** - Works beautifully on all devices
- **Interactive Terminal** - Try typing `help` in the shell section
- **Accordion Timeline** - Click to expand experience & education details
- **Joke Generator** - Random git commit messages for entertainment
- **Easter Egg** - Try the Konami code for a surprise!
- **Custom Avatar** - Personalized avatar image with enhanced styling

## 📁 Project Structure

```
├── index.html                    # Main HTML file
├── css/
│   └── styles.css               # All styling
├── js/
│   └── script.js                # All interactivity
├── assets/                       # Images and media
│   └── avatar.jpeg              # Profile avatar image
└── README.md                     # This file
```

## 🚀 Getting Started

Simply open `index.html` in your browser. No build process or dependencies needed!

## 🎨 Customization

### Colors
Edit the CSS variables in `css/styles.css`:
```css
:root {
  --bg: #10121a;           /* Background */
  --mint: #6ee7b7;         /* Accent color */
  --amber: #f5a95e;        /* Secondary accent */
  /* ... more variables */
}
```

### Avatar
Replace the avatar image in the `assets/` folder:
1. Add your avatar image to `assets/avatar.jpeg`
2. Update the image reference in `index.html`:
```html
<img src="assets/avatar.jpeg" alt="Your Name" class="avatar" />
```

### Content
Edit the HTML sections directly in `index.html`:
- Hero section
- About section
- Experience timeline
- Skills tags
- Projects
- Shell commands
